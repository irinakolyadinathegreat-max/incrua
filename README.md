# 🔥 AR Коза в Огне — Инструкция по запуску

## Что потребуется
- Аккаунт на GitHub (бесплатно)
- Ваш маркер: `маркер.png` ✅ (уже есть)
- Видео с огнём: `fire-video.mp4` (нужно добавить)
- 30 минут времени

---

## Шаг 1 — Компилируем маркер (.mind файл)

MindAR работает не с PNG напрямую, а с `.mind` файлом — это скомпилированный маркер.

### Как получить targets.mind:
1. Перейди на сайт: **https://hiukim.github.io/mind-ar-js-doc/tools/compile**
2. Нажми **"Upload Images"** → загрузи свой `маркер.png`
3. Нажми **"Start"** — подожди компиляцию
4. Нажми **"Export"** → скачается файл `targets.mind`

> ⚠️ Маркер должен быть чётким, с хорошим контрастом и деталями — у тебя всё отлично.

---

## Шаг 2 — Подготовь видео огня

Твоё видео должно быть:
- Формат: **MP4** (или WebM для прозрачности)
- Если нужен прозрачный фон огня → конвертируй в **WebM с альфа-каналом**
- Переименуй файл в: `fire-video.mp4`

> Если у тебя есть видео с чёрным фоном, в коде уже стоит `alphaTest: 0.05` — это уберёт почти чёрные пиксели автоматически.

---

## Шаг 3 — Создай репозиторий на GitHub

1. Зайди на **https://github.com** → войди в аккаунт
2. Нажми **"New repository"** (зелёная кнопка)
3. Название: например `goat-ar`
4. Поставь галку **"Public"**
5. Нажми **"Create repository"**

---

## Шаг 4 — Залей файлы

Загрузи в репозиторий все эти файлы:

```
goat-ar/
├── index.html        ← главный файл (из этого архива)
├── targets.mind      ← скомпилированный маркер (Шаг 1)
└── fire-video.mp4    ← твоё видео с огнём
```

### Как загрузить:
1. В репозитории нажми **"Add file"** → **"Upload files"**
2. Перетащи все три файла
3. Нажми **"Commit changes"**

---

## Шаг 5 — Включи GitHub Pages

1. В репозитории → **Settings** (вверху)
2. Слева → **Pages**
3. Source: **"Deploy from a branch"**
4. Branch: **main** / **(root)**
5. Нажми **Save**

Через ~2 минуты твой сайт будет доступен по адресу:
```
https://ВАШ_ЛОГИН.github.io/goat-ar/
```

---

## Шаг 6 — Сделай QR-код

1. Зайди на **https://qr-code-generator.com**
2. Вставь свой URL: `https://ВАШ_ЛОГИН.github.io/goat-ar/`
3. Скачай QR-код

---

## Как это работает для покупателя

```
Сканируют QR → Открывается ссылка в браузере →
Разрешают камеру → Наводят на фигурку козы →
Появляется огонь 🔥
```

Никаких приложений. Никакого VPN. Только браузер.

---

## Часто задаваемые вопросы

**Видео не играет на iOS?**
> Добавь в тег `<video>` атрибуты `muted playsinline webkit-playsinline` — уже есть в коде.

**Маркер не распознаётся?**
> Убедись что изображение освещено и не закрыто пальцами. Расстояние 15–40 см.

**Хочу изменить размер огня?**
> В `index.html` найди `width="1" height="1.8"` и подбери числа под своё видео.
